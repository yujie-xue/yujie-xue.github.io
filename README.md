# Yujie Xue | 薛宇劼

Personal website for research, selected experience, education and contact details.

**Website:** https://yujie-xue.github.io/

## Publishing

This site is plain HTML and CSS and has no build dependencies. GitHub Pages publishes the `main` branch from `/ (root)`.

Repository settings: https://github.com/yujie-xue/yujie-xue.github.io/settings/pages

## Updating

- `index.html`: biography, experience, education, presentations and contact details.
- `research/manufacturing-africa/index.html`: working paper summary.
- `assets/styles.css`: layout, typography and mobile styling.
- `assets/Yujie_Xue_CV.pdf`: public academic CV.
- `sitemap.xml`: indexable page URLs and dates. Change a page's date when its content changes.
- `robots.txt`: crawler access and sitemap location.

Keep canonical URLs and structured data consistent with the published pages. The website uses local assets and requires no cookies, analytics or external font requests.

## Google Search Console

1. Open https://search.google.com/search-console/ and add the **URL prefix** property `https://yujie-xue.github.io/`.
2. Choose HTML file or HTML tag verification. Add only the exact verification file or tag Google supplies; no verification token is currently included.
3. After verification, submit `sitemap.xml` and use URL Inspection to request indexing of the homepage.

Publishing and requesting indexing do not guarantee inclusion, timing or ranking in Google Search.
